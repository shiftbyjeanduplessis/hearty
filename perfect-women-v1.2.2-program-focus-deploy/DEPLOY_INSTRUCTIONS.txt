Perfect Women V1.2.0 Deploy Instructions

1. Unzip this file.
2. Replace the existing /perfect-women/ folder in the Hearty deploy/repo with the folder in this ZIP.
3. Do not copy the contents into the Hearty root. Keep the folder name exactly: perfect-women
4. Deploy/redeploy Hearty.
5. Test at: https://hearty.health/perfect-women/

Notes:
- This build is scoped to /perfect-women/ so it should not interfere with the main Hearty app.
- Existing local user data should remain because the local storage key is unchanged.
- Users may need to close/reopen the installed app or refresh once to get the new version.
